# Video Title Standard

Videos in the **Electrical & Electronic Systems** playlist use:

`Topic (with an optional verified focus) | Software`

- Put the circuit, component or demonstrated behavior first. Add a short focus only when the recording supports it. Natural punctuation may vary with the topic; no colon or dash is required.
- Use `Proteus ISIS` for the current examples and the actual software name for future examples.
- Keep the same complete title in YouTube, the example README heading, its video link, and this repository's index. Escape the literal pipe inside Markdown tables.
- Keep titles accurate and concise, with no unsupported performance or completeness claims. There is no fixed 60-character requirement.
- Preserve video IDs, example directories and native filenames when editorial wording changes.
