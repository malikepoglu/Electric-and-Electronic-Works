# Video Title Standard

Use this format for videos in the Electricity & Electronics playlist:

`Topic (with an optional verified focus) | Software`

- Put the circuit, component or demonstrated behavior first. Add a short focus only when the recording supports it. Use natural topic punctuation; keep the software suffix consistent.
- Use the actual software name at the end: `Proteus ISIS` for the current examples; `Logisim` for future examples made in Logisim.
- Keep titles accurate and concise. Avoid unsupported claims such as “best,” “ultimate” or guaranteed results. There is no fixed 60-character rule for this project.
- Use the same complete title in the YouTube title field, the example README heading and its video link, and the repository index video link. A literal pipe inside a Markdown table must be escaped as `\|`.
- Keep existing video IDs, example directories and native project filenames stable when changing a title.

Current examples:

- AND, OR & NOT Logic Gates and Truth Tables | Proteus ISIS
- 7447 vs 7448 BCD to 7-Segment Decoders | Proteus ISIS

This is the repository's editorial convention. It follows YouTube's guidance to describe the video accurately, keep titles succinct and place important words near the beginning; the exact punctuation is not a YouTube requirement. See [YouTube Help: Thumbnail & title tips](https://support.google.com/youtube/answer/12340300?hl=en).
